# Security Policy

If you believe you've found a security vulnerability in SimpleWarp, please do **not** open a public
issue or pull request. Report it through a private
[GitHub Security Advisory](https://github.com/wynn5a/simplewarp/security/advisories/new) on this
repository.

Vulnerabilities in upstream Warp itself (anything not specific to this fork) go to
[security@warp.dev](mailto:security@warp.dev).
